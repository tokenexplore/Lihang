# 朴素贝叶斯和高斯贝叶斯法
我来为您总结各种贝叶斯方法的相同点、基础假设和差异：

**相同点**
1. 都基于贝叶斯定理：
$$P(C_k|\mathbf{x}) =
\frac{P(\mathbf{x}|C_k)P(C_k)}{P(\mathbf{x})}$$
1. 都使用最大后验概率决策：
$$\hat{y} = \arg\max_{k} P(C_k|\mathbf{x}) \propto
\arg\max_{k} P(C_k)P(\mathbf{x}|C_k)$$

共同基础假设

**3. 特征条件独立假设：**
$$P(\mathbf{x}|C_k) = P(x_1, x_2, ..., x_n|C_k) =
\prod_{i=1}^{n} P(x_i|C_k)$$

主要差异：对 $P(x_i|C_k)$ 的分布假设

| 方法类型 | 对 $P(x_i\|C_k)$ 的假设 | 适用场景 |
|---------|---------------------|----------|
| 高斯朴素贝叶斯 | 高斯（正态）分布 | 连续数值型特征 |
| 多项式朴素贝叶斯 | 多项式分布 | 非负整数特征（如词频） |
| 伯努利朴素贝叶斯 | 伯努利分布 | 二值特征 |
| 标准贝叶斯 | 无特殊假设，估计完整联合分布 |任意，但需要大量数据 |

数学表达式对比

通用朴素贝叶斯（所有朴素贝叶斯的基础）：
$$P(C_k|\mathbf{x}) \propto P(C_k)\prod_{i=1}^{n}
P(x_i|C_k)$$

各变种的具体 $P(x_i|C_k)$ 形式：

- 高斯: $P(x_i|C_k) = \frac{1}{\sqrt{2\pi\sigma_{ki}^2}}\exp\left(-\frac{(x_i-\mu_{ki})^2}{2\sigma_{ki}^2}\right)$
- 多项式: $P(x_i=v|C_k) = \frac{N_{v,C_k} + \alpha}{N_{C_k} +
\alpha \cdot |V_i|}$
    - 多项式/朴素贝叶斯确实是用频率来估计 $P(x_i|C_k)$ 的
- 伯努利: $P(x_i|C_k) = p_{ki}^{x_i}(1-p_{ki})^{1-x_i}$

**总结:**
所有朴素贝叶斯方法都共享相同的"朴素"假设（特征条件独立），但对每个特征的具体分布做了不同的假设，这就是它们的主要区别。
